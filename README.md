# Coffee Sales Forecasting Dashboard

## 📌 Project Overview

This project is a machine learning-based coffee sales forecasting system developed using Python and Streamlit.

The dashboard analyzes historical coffee transaction data to:

- Forecast future sales
- Predict revenue trends
- Identify peak-demand hours
- Compare machine learning models
- Visualize uncertainty using confidence intervals

The system helps businesses make data-driven decisions related to inventory management, staffing, and operational planning.
